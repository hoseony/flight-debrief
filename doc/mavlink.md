# MAVLink

## usage
You need to make out dir. That's where all the logs will be stored. You can clear the log with the shell script that is in this dir.

### note from the author
MAVLink is fairly well documented, I wrote my own parser to study the protocol and study programming on Linux system. If you are planning to implement your own MAVLink library, please don't. I was able to do this because my project was fairly simply in terms of the messages to implement/parse. Once you get hang of how to make it, you should probably use the library they provide.
